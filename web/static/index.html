✅ Web Server Running!

The Drift web server is running successfully. The full HTML GUI will be implemented next.

Available API Endpoints:

User Authentication

POST /api/login

Login with username and password

Simulation Management

POST /api/simulation/start

Start a new simulation

GET /api/simulation/status?username={username}

Get simulation status for a user

POST /api/simulation/cancel

Cancel a queued or running simulation

Results & Progress

GET /api/progress/{username}/{modelname}

Get current progress of a simulation

GET /api/results/{username}/{modelname}

List result files

GET /api/results/{username}/{modelname}/{filename}

Download a specific result file

Admin

GET /api/admin/queue

View simulation queue status

GET /api/admin/users

List all users

Test the API
